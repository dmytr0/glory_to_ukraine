## Yagi antenna adjustable - a model for tuning a Yagi antenna with movable elements

Designed for finding the geometry of a Yagi antenna (element lengths and spacing) before building a permanent antenna. The driven element, reflector and director(s) slide along the base - you can quickly change their position, find the optimal parameters for your frequency, and then reproduce the result in a "permanent" build.

![](/Yagi_adjustable/media/anim.gif)

Body.stl - base, length 33cm. It does not fit straight on a Bambu Lab bed (25.5cm), but fits diagonally - rotate the part at an angle when slicing.

Reflector travel range - up to 90mm from the driven element.

Director travel range (if there is only one) - up to 180mm from the driven element.

vibrator_X.stl - driven element for a fixed rod diameter X mm: 1.5, 1.8, 2, 2.5, 3.5.

element_adjustable_X.stl / element_adjustable_X_wide.stl - movable element (director or reflector) for the same rod diameter. "_wide" is a version with a wider holder for the movable element. For the 3.5mm diameter only the "_wide" version is available.

The rod diameter is fixed for each element model - other diameters won't fit, pick the file matching your rod.
