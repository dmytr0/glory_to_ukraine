## Yagi antenna adjustable - модель для налаштування Yagi антени з пересувними елементами

Призначена для підбору геометрії Yagi антени (відстані паразитних елементів) перед виготовленням постійної антени. Вібратор закріплений нерухомо, а рефлектор і директор(и) рухаються вздовж основи - можна швидко змінювати їх положення, знайти оптимальні параметри під свою частоту, а вже потім повторити результат у "постійній" конструкції.

Коли параметри підібрані - готовий каркас під свою частоту можна згенерувати на [paramodels-3d.dimonick.win/models/yagi-antenna](https://paramodels-3d.dimonick.win/models/yagi-antenna) - це параметрична модель постійної Yagi антени.

![](/Yagi_adjustable/media/anim.gif)

Body.stl - основа, довжина 33см. По прямій не влазить на стіл Bambu Lab (25.5см), але влазить по діагоналі - при нарізці розверніть деталь під кутом.

Діапазон руху рефлектора - до 90мм від вібратора.

Діапазон руху директора (якщо він один) - до 180мм від вібратора.

vibrator_X.stl - вібратор (активний елемент) під фіксований діаметр прутка X мм: 1.5, 1.8, 2, 2.5, 3.5.

element_adjustable_X.stl / element_adjustable_X_wide.stl - пересувний елемент (директор або рефлектор) під той самий діаметр прутка. "_wide" - варіант з ширшим тримачем рухомого елемента. Для діаметра 3.5мм є лише "_wide" версія.

Діаметр прутка фіксований під кожну модель елемента - інші діаметри не підійдуть, підбирайте файл під свій пруток.
